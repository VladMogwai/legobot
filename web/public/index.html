legobot ● проверяю…

Пиксель-арт → модель LEGO: файл для Studio, PDF-инструкция, список деталей. Всё считается в твоём браузере — сервера нет.

Подходит пиксель-арт с чётким контуром и фото мозаики: фигурку бот вырежет из фона сам, фото панно соберёт панно целиком — тип определяется по картинке. Живопись, градиенты и HD-иллюстрации в кирпичах не читаются. Первая загрузка движка — около 15 МБ и полминуты, дальше из кэша; сборка — секунды.

Уже правил модель в Studio? — получишь инструкцию, список деталей и превью.
